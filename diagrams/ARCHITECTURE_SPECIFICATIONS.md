# System Architecture Specifications
## CareerCoachAI Engineering Reference

This directory contains the visual and specification assets for CareerCoachAI's architecture:

- **[`system-architecture.svg`](system-architecture.svg):** High-resolution vector graphic illustrating the Client Tier (Vercel), API Tier (Render), AI Tier (Google DeepMind Gemini), and Data Tier (MongoDB Atlas).
- **[`system-architecture.mmd`](system-architecture.mmd):** Editable Mermaid source for the complete system topology.
- **[`user-workflow.mmd`](user-workflow.mmd):** Editable Mermaid sequence diagram covering authentication, resume ingestion, and the interactive mock interview flow.
